# UI / Research Refinement Pass

- Advertising no longer uses ON/OFF buttons. A 0% slider is off; any value above 0% is active.
- Each advertising channel can spend at most 1% of current daily gross earnings. Slider 0–100% scales within that cap.
- Advertising costs and subscriber gains are displayed per in-game day.
- Rivals are grouped by region in collapsible sections, with multiple rivals supported per region.
- Contract expiry and next-payment timing are displayed using in-game days/months.
- IPO revenue is displayed per in-game month instead of a real-time hourly label.
- Infrastructure income is displayed per in-game day.
- Infrastructure BUY controls occupy approximately one third of each asset row.
- Research layout is ordered by the numeric part of node IDs with fixed T/S/A/C columns; maximum four nodes per row.
- The next era is rendered dimmed so cross-era prerequisite links remain visible.
- T7 now depends on C1 and has non-zero duplex-telegraph effects; T6 remains connected to S8 without inventing a fake same-era dependency.
- Source game files and Android assets are synchronized.
