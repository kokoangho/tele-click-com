# Infrastructure System

## Infrastructure Types by Era

### Era 1 (Analog Dawn)
- Copper Trunk (twisted pair) — 1 circuit
- Manual Switchboard — 100 subs, 5 operators
- Pole Line (aerial cable) — right‑of‑way
- Local Exchange Building — 1 city
- Telegraph Line — message relay

### Era 2 (Electromechanical)
- Coaxial Backbone — 600 circuits
- Microwave Tower — 480 circuits
- Crossbar Exchange — 10,000 subs
- Submarine Cable (TAT‑1) — 36 circuits, intercontinental
- Mobile Tower (MTS/IMTS) — 50 mobile users
- Repeater Station (vacuum‑tube) — long‑haul enablement

### Era 3 (Digital)
- Fiber Optic Cable — 10 Gbps
- Digital CO (#5ESS/DMS) — 100k subs
- Cell Tower (1G/2G) — 500 subs
- Data Center — RP + cloud service
- VSAT Earth Station — 50 remote links
- SONET Ring (self‑healing) — resilient backbone
- SS7 STP (Signal Transfer Point) — signaling network

### Era 4 (Broadband)
- FTTH OLT (GPON) — 32 subs per port
- LTE eNodeB — 500 subs, 150 Mbps
- DWDM Terminal — 40×10G channels
- IP Core Router (Cisco CRS, Juniper PTX) — Tbps
- Edge Cache Node — latency reduction
- Tier‑3 Data Center — colocation revenue
- MPLS PE Router — enterprise VPN

### Era 5 (Autonomous)
- 5G gNodeB (mmWave) — 1 Gbps per user
- LEO Satellite Terminal — global coverage
- AI‑NFV Core (cloud‑native) — auto‑scaling
- Edge AI Server — real‑time inference
- Hollow‑core fiber link — near light‑speed
- MEC node — single‑digit ms latency

### Era 6 (Interspace)
- Quantum Repeater — entangled link
- Lunar Relay Station — Moon coverage
- Neutrino Transceiver — any‑depth link
- Dyson Swarm Node — solar system coverage
- Interplanetary Gateway — DTN bundle relay

## Region / Grid System
- **Hierarchy:** City → State → Country → Continent → Global → Lunar → Mars → Belt → Interstellar
- **Penetration %** = subs / population (sigmoid: fast early, slow late)
- **Congestion:** demand > capacity → revenue penalty until upgrade
- **Transport logistics:** must deploy inter‑region cable/satellite before serving

## Upgrades Depth
- Each infra: Level 1–100, exponential cost × linear capacity
- **Automation:** RSO → NOC → AI → zero‑touch
- **Redundancy:** N+1 → 1:1 → ring diversity → geo‑redundancy
